# TEKNOFEST in Arabic 2026

Public landing page for the Ibtikar conference in Istanbul (21–22 November 2026).

## Scripts

```bash
npm install
npm run dev      # http://localhost:5925
npm run build
npm run deploy   # Cloudflare Worker + teknfest.ibtikar.tr
```

Live: [teknfest.ibtikar.tr](https://teknfest.ibtikar.tr)

Languages: Arabic (default), English, Turkish. Copy lives in `src/i18n/dictionaries`.
